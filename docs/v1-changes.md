## Поменять

| Пункт ТЗ | Как реализовано |
|---|---|
| Ставка Девелопмента по месяцам до сдачи | таблица `DEV_RATE_TABLE` и `devRateFor()`, ставка объекта пересчитывается на сегодня; выбор срока 1/2/3 года убран из оферты (`api/calc.ts`, `api/mocks.ts`) |
| Досрочный выход по ДДУ | 3 месяца ожидания, ставка × 0,5, полные месяцы, возврат = тело + пересчёт − выплачено − налог, 30 дней, очередь (`earlyExitQuote`, `EarlyExit`) |
| «Доля в объекте» → «Ваша доля в общем объёме инвестиций» | подпись в оференсе и карточке (`ui.shareVolume`) |
| Доход — «расчётный по целевой ставке» | подпись чипа и карточки аналитики; фактически выплачено — отдельной строкой из CRM (`paid`) |
| Партнёрство: срок «индивидуально, до 30 мес.», ставка «целевая до 55%», только заявка | `productRules.partnership`, `Invest` (consult-only) |
| Минимум $100, максимума нет, поле суммы без лимита 6 цифр | `min` в центах, `max: null`, ввод до 12 цифр |
| Слово «целевая» у ставок + дисклеймер | `ui.targetRate`, `ui.rateNotGuaranteed` на карточке объекта и в оферте |
| Пополнение: реквизиты + QR + номер клиента + предупреждение | `TopUp`, `qrcode.react` |
| Вывод: сумма, сохранённые счета, 3 рабочих дня, статусы | `Withdraw` + заявки |
| Оформление: способ подписания, итог «Заявка принята» | `Invest`, шаги `office / scan / notary` |
| Профиль: адреса, лицензия, счета, автовывод, документы | `Profile` |
| Данные из `data.ts` в API-слой с моками | `src/api/*`, экраны читают через `useQuery` |
| Состояния: загрузка, пусто, ошибка, сессия истекла | `Loading`, `EmptyState`, `ErrorState`, `ApiError` |

## Оставить

Метки объектов, калькулятор, этапы стройки, аналитика, новости, темы, личный счёт, RU/KY — сохранены.

## Как проверить

- `npm run dev`, демо-состояния: `?state=error`, `?state=empty`, `?state=loading`, `?state=unauthorized`.
- Автотест приёмки: `qa-v1.mjs` (вне репозитория) — 48 проверок: гость, вход, оферта, заявки, пополнение, вывод, досрочный выход с проверкой формулы, документы с замечаниями, состояния, две темы, 320/390.
- Аудит вёрстки: 80 сканов (4 ширины × 2 темы × гость/авторизованный × 5 экранов) — без ошибок консоли, без горизонтального скролла и переполнений; остаются только плотные контролы 36–40 px (переключатель периода, ссылки «Все», кнопки внутри карточек).

## Что не делал (не относится к фронту)

Бэкенд и CRM, OpenAPI-контракт, SMS-провайдер, Firebase, сборка Capacitor, публикация в сторах, юридические тексты и проверка КР-локализации — зоны Жени и Дани по ТЗ.
